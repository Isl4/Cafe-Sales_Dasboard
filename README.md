# Cafe-Sales_Dasboard 
## Project Overview
This project analyses cafe sales data using Excel and Power Query.
The objective was to clean raw sales data, build interactive visualisations, and identify business insights through KPI tracking and dashboard design.

## Dataset file link on Github:
- <a href="https://github.com/Isl4/Cafe-Sales_Dasboard/blob/main/Clean_Cafe_Sales.xlsx">Dataset</a>

## Key Insights
Salad generated the highest revenue.
Digital Wallet was the most used payment method.
In-store sales exceeded takeaway sales.
Monthly revenue remained relatively stable.

## Data Cleaning
Replaced UNKNOWN values.
Removed blank records.
Fixed data types.
Validated Total Spent values.
Checked for duplicates.
